# HelloSchool

HelloSchool is a technical education website for practical training in mobile phone repair, computer maintenance, and electronics troubleshooting.

## Stack

- Next.js 16, React 19, and TypeScript
- Tailwind CSS
- Prisma with MySQL

## Development

Install dependencies with pnpm, configure `DATABASE_URL` in `.env`, and generate the Prisma client:

```bash
pnpm install
pnpm prisma:generate
pnpm dev
```
